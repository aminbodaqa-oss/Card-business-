Vindora Smart NFC Business Card — Mohammed Ismail

- mohammed.php: standalone responsive profile page
- mohammed-qr.png: QR code pointing to https://vindora.whf.bz/mohammed
- .htaccess-snippet.txt: rewrite rule to enable the clean /mohammed URL

Install:
1. Upload mohammed.php and mohammed-qr.png to the website document root.
2. Add the rewrite rule from .htaccess-snippet.txt to the EXISTING .htaccess file. Do not overwrite existing rules.
3. Open https://vindora.whf.bz/mohammed and test all buttons and the QR.
4. Program the NFC chip to open exactly: https://vindora.whf.bz/mohammed

The page includes phone, WhatsApp, email, Facebook, Instagram, Vindora website, and downloadable vCard.
